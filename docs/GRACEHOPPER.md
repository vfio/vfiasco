# GraceHopper H100 GPU passthrough

NVIDIA GraceHopper H100/GH200 GPUs live on a non-zero PCI domain (`0009:...`)
and require `nvgrace_gpu_vfio_pci` for proper PASID/ATS support.  The device
must be bound to `pci_pf_stub` before tests run; `virsh nodedev-detach` then
picks `nvgrace_gpu_vfio_pci` automatically.

## Domain topology

The `centos10_gh` domain carries the full aarch64 + SMMUv3 topology required
for passthrough — generated by `setup_domain.py --domain centos10_gh`:

- **`<cpu><numa>`** with cells 0-8: cell 0 holds all vCPUs and RAM; cells 1-8
  are empty placeholders for the H100 HBM stacks.

- **`<pcihole64 unit='KiB'>4294967296</pcihole64>`** on the pcie-root
  controller (4 PiB), required to accommodate the H100's 128 GB framebuffer BAR.

- **`<controller type='pci' model='pcie-expander-bus'>`** (pxb-pcie, index 1,
  `busNr=254`) plus a `pcie-root-port` (index 2) for the GPU guest bus.

- **`<iommu model='smmuv3'>`** with `accel='on' ats='on' ril='off'
  ssidSize='20' oas='48'` and `pciBus='1'` (the pxb-pcie index).

The hostdev element (`domain_xml/gh100_gpu.xml`) is injected by the standard
device injection path at test time, with `managed='yes'`, `<driver iommufd='yes'/>`
and `<acpi nodeset='1-8'/>`.

## Host setup (once)

```bash
# Bind GPU to pci_pf_stub so virsh nodedev-detach picks nvgrace_gpu_vfio_pci
modprobe pci_pf_stub
echo "10de 2342" > /sys/bus/pci/drivers/pci-pf-stub/new_id
virsh nodedev-detach pci_0009_01_00_0

# 512M hugepages (default hugepage size on GraceHopper)
echo 64 > /sys/kernel/mm/hugepages/hugepages-524288kB/nr_hugepages
```

## Domain setup (once)

```bash
python3 utils/setup_domain.py --domain centos10_gh
virsh start centos10_gh   # complete firstboot, then shut it down
```

## domains.ini entry

```ini
# GraceHopper H100 GPU domain — aarch64 + SMMUv3, 16 GiB RAM, 16 vCPUs.
# platform=grace: setup_domain.py generates the domain XML (virsh define),
# and iommufd is enabled automatically at runtime.
# Hugepages must be pre-allocated on the host (default size is 512M on Grace).
[centos10_gh]
name                        = centos10_gh
mac_addr                    = c0:ff:ee:00:00:54
image_name                  = centos10_gh.qcow2
distro                      = centos10
platform                    = grace
memory                      = 16384
vcpu                        = 16
```

## host_devices.ini entry

```ini
# GraceHopper H100 GPU — non-zero PCI domain (0009:...), no SR-IOV, no network check.
[gh100_gpu]
device_addr        = 0009:01:00.0
```

## Running the boot test

```bash
# --iommufd is enabled automatically when the domain has platform=grace
python3 vfiasco.py \
  --feature pf \
  --device_name gh100_gpu \
  --domain centos10_gh \
  --machine_type virt \
  --test_list boot_test
```
